# Ham Radio Lab — prototype

## What this prototype includes

- General / Amateur Extra selector
- Small demo question set with explanations and subject filters
- Flashcards
- Virtual HF radio controls and simulated spectrum
- Visual lessons for propagation, circuits, and antennas
- Responsive layout for mobile and desktop

## Important before public launch

The question items in this prototype are illustrative demo questions, not the complete current official FCC question pools. Before presenting this as a full exam-prep product, verify the current official question pools, answer keys, permissions/attribution requirements, and update process. The radio is a visual simulation only; it does not connect to radio hardware or the internet.
